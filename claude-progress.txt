DATABASE SCHEMA
==============================================================================

Type: PostgreSQL (117.72.207.52:5432/linker-mind)
Tables: 13
Full-Text Search Tables: 2 (contents_fts, notes_fts)

Table List:
  1. contents           - Main content storage
     Fields: id, source_type, content_type, title, url, raw_content, summary,
             main_content, ai_analysis (JSONB), metadata (JSONB), favorited,
             archived, reading_progress, created_at, updated_at, processed_at

  2. notes              - Progressive notes
     Fields: id, content_id, note_type, content, highlights (JSONB),
             summary_layers (JSONB), project_tags (JSONB), created_at, updated_at

  3. nodes              - PARA organization (Projects, Areas, Resources, Archive)
     Fields: id, node_type, name, description, parent_id, status, icon,
             tags (JSONB), properties (JSONB), target_date, completed_at

  4. node_contents      - Content-node relationship
     Fields: node_id, content_id, added_at (PK: node_id, content_id)

  5. links              - Bidirectional links
     Fields: id, source_id, target_id, link_type, strength, created_at, updated_at

  6. learning_sessions  - Learning session tracking
     Fields: id, content_id, duration, comprehension, next_review, session_data (JSONB)

  7. review_schedules   - Spaced repetition scheduling
     Fields: content_id, next_review, interval, ease_factor, review_history (JSONB)

  8. skills             - Skill management
     Fields: id, skill_name, level, parent_ids (JSONB), metadata (JSONB), progress (JSONB)

  9. skill_contents     - Skill-content relationship
     Fields: skill_id, content_id, order_index

  10. creation_projects  - Creation projects
     Fields: id, project_type, outline, status, metadata (JSONB), citations (JSONB)

  11. citations          - Citation tracking
     Fields: id, project_id, source_content_id, citation_data (JSONB)

  12. inbox             - Inbox items
     Fields: id, content_id, raw_input, title, url, source_type, status,
             quick_tags (JSONB), properties (JSONB)

  13. tags              - Tag management
     Fields: id, name, color, use_count
